# Актуалізації: єдиний реєстр публікацій

На тематичних сторінках `model.html`, `feniks.html`, `demo.html`, `domain.html` **праворуч від основного тексту** показується окреме мінімалістичне вікно з **до 12 останніх тематичних прев’ю** (дата, назва, коротка анотація), відібраних за атрибутом `topics`. Список має власну вертикальну прокрутку; заголовок і посилання **«Всі статті →»** залишаються видимими над ним. На екранах до 1180 px добірка переходить під основний текст, а на мобільних пристроях прокручується разом зі сторінкою. Посилання веде до `aktualizatsii.html`, де всі записи доступні з пошуком та фільтром.

Джерело даних: `assets/updates.json`. У реєстрі є зовнішня публікація ISTOTA, внесена 2026-11-23; дата запису означає дату включення до добірки Archeonomus, а не дату публікації офіційного сайту. Нові матеріали додаються як елементи `items`, без вигаданих новин або демонстраційних записів.

## Приклад формату (це шаблон, не опублікована новина)

```json
{
  "version": 1,
  "items": [
    {
      "id": "update-001",
      "date": "2026-11-21",
      "title": "Назва справжньої публікації",
      "summary": "Авторська анотація матеріалу без припущень або автоматичної генерації.",
      "type": "publication",
      "source": "Назва джерела",
      "url": "https://example.org/actual-article",
      "topics": ["feniks", "model"]
    }
  ]
}
```

Допустимі значення `topics`: `model`, `feniks`, `demo`, `domain` (персональний домен). Один матеріал може належати кільком темам, але зберігається лише в одному записі. Дата має формат ISO `YYYY-MM-DD`; останні визначаються за нею. `type`: `publication` — зовнішня публікація; `authorial` — авторська актуалізація; `discussion` — питання для обговорення. `source` і `url` необов'язкові; посилання назовні приймаються лише через HTTPS.

Після редагування `updates.json` обидва місця відображення оновлюються автоматично без ручної зміни трьох сторінок. Цей етап **не включає адміністративний редактор або автоматичну публікацію з кабінету**; потрібно буде реалізувати окремо.

**Оракул:** паспорт публікації поки не інтегрований у серверну контекстну базу Оракула. Не показувати дію «Обговорити з Оракулом» як працюючу для новин без зв'язування їх ID із контекстним пошуком.

**Дизайн:** лише текст, розділювачі та тонка рамка посилання, відповідно до чинного мінімалістичного оформлення сайту.
